# أَدْوَم | Adwam

> **رفيق رحلة حفظ القرآن**  
> خطة شخصية، مراجعة ذكية، ومساعدة موثوقة للاستمرار.

**أدوم** منصة رقمية تساعد الحافظ على تحويل الحفظ من جهد متقطع إلى رحلة مستمرة قابلة للتكيّف. تجمع المنصة بين تخطيط الورد، التقييم الذاتي، المراجعة الذكية، ميزة **«أنقذ وردي»**، ومساعد قرآني يلتزم بالمصادر وحدودها.

تم تطوير المشروع ضمن **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026**.

---

## الفكرة

تتعثر رحلة الحفظ غالبًا في ثلاث نقاط:

- **غياب خطة واضحة:** ماذا أحفظ اليوم؟ ومتى أراجع ما حفظته؟
- **ضعف تشخيص مواضع الضعف:** تكرار الحفظ دون معرفة ما يحتاج مراجعة فعلًا.
- **انقطاع الاستمرارية:** يوم فائت أو ظرف طارئ قد يحوّل الخطة إلى عبء أو انقطاع.

أدوم يبني رحلة مترابطة تبدأ من الخطة، ثم الحفظ والتقييم، ثم المراجعة، ثم التكيّف مع تقدم المستخدم وظروفه.

---

## ماذا يقدم أدوم؟

### 1. خطة شخصية
يحدد المستخدم:
- نقطة البداية
- أيام الحفظ
- مقدار الورد
- هدف الختمة

ثم تُبنى رحلة قابلة للتعديل بدل الاعتماد على ورد ثابت لا يتغير.

### 2. مصحف وورد يومي
يفتح المستخدم وردًا حقيقيًا من خطته، مع عرض النص القرآني بالرسم العثماني من مصدر موثوق.

### 3. «اختبرني»
وضع استرجاع يساعد المستخدم على اختبار حفظه دون الاعتماد المستمر على النظر للنص، ثم يسجل تقييمه:
- متقن
- عادي
- يحتاج مراجعة
- لم أتمكن

### 4. مراجعة ذكية
نتيجة التقييم تؤثر في أولوية المراجعة وموعدها:
- المواضع المتقنة تتباعد مراجعتها تدريجيًا
- المواضع الضعيفة تعود في وقت أقرب
- يظهر للمستخدم **سبب ظهور المراجعة**

### 5. «أنقذ وردي»
عند تعذر ورد اليوم، لا تُكسر الخطة. يمكن إعادة توزيع الحمل أو تخفيفه بطريقة تحافظ على الاستمرارية.

### 6. مساعد أدوم
مساعد قرآني مصمم ليكون **مقيدًا بالمصدر** لا مساعدًا عامًا يجيب من ذاكرته فقط.

يدعم سياقات مثل:
- تفسير الآية
- المتشابهات اللفظية
- مساعدة الحفظ
- توضيح سبب الالتباس بين موضعين
- أسئلة عامة ضمن النطاق الذي تغطيه المصادر

إذا لم تتوفر مادة موثوقة كافية، يمتنع المساعد عن التخمين ويوضح حدود مصادره.

## حلقة الذكاء في أدوم

```text
التخطيط
   ↓
الورد القرآني
   ↓
اختبار الاسترجاع / التقييم الذاتي
   ↓
اكتشاف مواضع الضعف
   ↓
جدولة المراجعة
   ↓
تحديث خريطة الإتقان
   ↓
تكييف الخطة
   ↓
الاستمرار
```

الذكاء الاصطناعي في أدوم ليس مجرد شات جانبي؛ الهدف أن يؤثر في رحلة المراجعة نفسها.

## الموثوقية والسلامة العلمية

يعتمد تصميم أدوم على مبادئ واضحة:

- **النص القرآني لا يولده النموذج.**
- أي تفسير أو معلومة دينية يجب أن تكون قابلة للتتبع إلى مصدر.
- يُفصل بين النص المنقول من المصدر وبين تبسيط أدوم.
- عند عدم كفاية المصدر تكون الأولوية للامتناع بدل التخمين.
- لا يقدم أدوم فتوى شخصية مستقلة.
- الأسئلة التي تتطلب حكمًا خاصًا بالمستخدم تُحال لأهل الاختصاص.
- لا تُرسل بيانات المستخدم الشخصية للمساعد عند عدم الحاجة.

## التشغيل محليًا

### المتطلبات
- Node.js 20+
- pnpm

### التثبيت

```bash
pnpm install
```

أنشئ ملف `.env` من `.env.example` وضع القيم المطلوبة محليًا فقط.

```bash
pnpm dev
```

ثم افتح الرابط الذي يظهر في الطرفية.

### التحقق قبل التسليم

```bash
pnpm run check
pnpm test
pnpm run build
```

> لا ترفع `.env` أو مفاتيح API أو بيانات المستخدمين إلى GitHub.
