# أدوم | Adwam

أدوم منصة لحفظ القرآن ومراجعته برحلة شخصية قابلة للتكيّف، تجمع بين الورد اليومي، التقييم الذاتي، المراجعة المتباعدة، «أنقذ وردي»، ومساعد معرفي موثّق بالمصادر عند اكتمال ربط خدمة RAG.

## السيناريو الأساسي الذي يجب أن يعمل في العرض
1. إنشاء/بدء جلسة العرض ثم إعداد خطة الحفظ.
2. فتح ورد اليوم وقراءة الصفحة من مصدر القرآن المتحقق.
3. إكمال الورد يدويًا أو اختيار «اختبرني» عند توفر خدمة التسميع.
4. تسجيل التقييم وتحديث الموضع، الاستمرارية، والمراجعات القادمة.
5. فتح «مراجعتي» وفهم سبب ظهور كل مراجعة.
6. استخدام «أنقذ وردي» لإعادة تكييف اليوم دون كسر منطق الخطة.
7. فتح «مساعد أدوم» من القائمة أو من آية محددة. المساعد يعرض المصادر أو يمتنع عند عدم كفايتها، ولا يولّد فتوى شخصية.

## المزايا الأساسية
- Onboarding لخطة الحفظ والمراجعة.
- ورد يومي ومصحف تفاعلي.
- تقييم ذاتي مع جدولة مراجعة.
- Recovery / «أنقذ وردي».
- تقويم وسجل تقدم وخريطة إتقان.
- مساعد أدوم مع سياق آية، حالات امتناع، ومصادر.
- واجهة عربية/إنجليزية وثيمات Sand/Sage/Night.

## حالة التكامل
- **Quran text:** متصل حاليًا بالمصدر المحدد في `shared/quran.ts`.
- **RAG:** واجهة وعقد تكامل جاهزان؛ لا يجب ادعاء أن النسخة الحالية تقدّم تفسيرًا حقيقيًا حتى ربط corpus/service موثقة.
- **STT/recitation:** الواجهة ومسار التسجيل موجودان؛ `recitationService.ts` يتعمد الفشل بأمان بدل عرض نتائج وهمية حتى ربط endpoint حقيقي.
- **Auth:** النسخة الحالية تحتوي جلسة عرض محلية في الواجهة، بينما البنية الخلفية تتضمن session/OAuth infrastructure. لا تُقدَّم جلسة العرض على أنها مصادقة إنتاجية.

## تشغيل محلي
```bash
pnpm install
pnpm dev
```

قبل النشر أنشئ `.env` محليًا من `.env.example`. لا ترفع أي مفاتيح أو بيانات حساسة إلى GitHub.

## ملفات التسليم المهمة
- `ASSISTANT_INTEGRATION_CONTRACT.md` — عقد الربط مع RAG.
- `SECURITY_REVIEW.md` — مراجعة الأمان ومسؤوليات frontend/backend.
- `SOURCES_AND_LICENSES.md` — سجل المصادر والأدوات والتراخيص.
- `QA_CHECKLIST.md` — اختبارات العرض والتسليم.
- `DELIVERY_CHECKLIST.md` — قائمة المخرجات النهائية.
- `PRE_CHALLENGE_DISCLOSURE.md` — قالب الإفصاح عن النسخة السابقة والإضافات، دون اختلاق أو تأريخ رجعي.

## سياسة السلامة العلمية
المساعد يميّز بين المصدر والشرح، يمتنع عند غياب المرجع الكافي، ولا يستقل بالفتوى الشخصية. أي ميزة إحالة بشرية إلى مختص تُعرض كخطة مستقبلية حتى وجود شراكة وتشغيل فعلي.
